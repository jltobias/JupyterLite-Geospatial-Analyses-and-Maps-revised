# Data, video, and source notes

## Bundled local data

- `content/data/montreal_districts.geojson`: real Montreal electoral district polygons from Plotly package example data (`election.geojson`).
- `content/data/election.csv`: election attributes from Plotly package example data.
- `content/data/carshare.csv`: car-share point sample from Plotly package example data.
- `content/data/health_facilities_training_points.csv`: small training layer of public health-facility coordinates for browser mapping exercises. Replace with healthsites.io exports for operational work.
- `content/data/nyc_taxi_pickups_tiny.csv`: tiny teaching sample of pickup coordinates. Replace with NYC TLC trip records or Kaggle-hosted taxi datasets for larger exercises.
- `content/data/meuse_training_points.csv`: tiny training table representing Meuse-style heavy-metal sampling concepts for browser-safe map instruction. Use the full canonical Meuse dataset in desktop/server geostatistical workflows.

## Live/remote examples used in notebooks

- OpenStreetMap tile basemaps and Overpass query examples.
- NASA GIBS WMTS true-color imagery tiles.
- USGS earthquake GeoJSON feed, a Data.gov-linked federal open-data source.
- h3-js CDN for browser-side hexagon generation.
- deck.gl and MapLibre CDNs for 3D browser visualization.

## Videos embedded or referenced

- NASA Worldview / Earthdata tutorial videos.
- My NASA Data Earth System Data Explorer tutorial.
- General geospatial visualization video placeholders can be replaced with an agency-approved playlist.

## Boundary rule

Administrative or political boundaries in these notebooks should be real-world boundaries from documented sources. Do not present synthetic polygons as real administrative geography.
